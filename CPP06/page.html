Understanding C++ Casts

A comprehensive walkthrough of the 4 C++ casting operators and detailed implementation guides for Module 06 exercises.

1. Theory: The 4 C++ Casts

C++ introduced 4 specific casting operators to replace unsafe C-style implicit and explicit casts (type)value, making type conversions explicit, intentional, and checked at compile/run time.

Compile-Time

static_cast

Handles standard implicit conversions between basic scalar types (e.g. int to float) and upward/downward class pointer conversions in known class hierarchies.

double d = 42.42;
int i = static_cast<int>(d);
Run-Time (RTTI)

dynamic_cast

Safely casts pointers/references along polymorphic inheritance hierarchies. Uses RTTI (Run-Time Type Information) and requires at least one virtual function.

Base* b = new Derived();
Derived* d = dynamic_cast<Derived*>(b);
// Returns nullptr if invalid!
Constness

const_cast

Adds or removes const or volatile qualifiers from a variable pointer or reference. Does not alter the underlying type memory representation.

const char* str = "Hello";
char* p = const_cast<char*>(str);
Bit Reinterpretation

reinterpret_cast

Low-level cast that reinterprets raw bit patterns (e.g., pointer to uintptr_t integer or unrelated struct pointer conversions). Highly dangerous if misused.

Data* data = new Data();
uintptr_t raw = reinterpret_cast<uintptr_t>(data);
Cast Type When Checked? Primary Use Case Safety Level
static_cast Compile-Time Primitive scalar conversions, upcasts & safe base-derived conversions Medium (Requires valid type relationships)
dynamic_cast Run-Time Safe downcasting in polymorphic trees (requires virtual destructor) Very High (Returns nullptr or throws exception)
const_cast Compile-Time Adding or casting away const modifier High (Dangerous if writing to original const data)
reinterpret_cast Compile-Time Pointer-to-integer, pointer-to-unrelated-pointer bit conversions Low (Raw memory bit interpretation)

Key Requirements & Solution Architecture

  • Pure static class (non-instantiable: private constructors and destructor).
  • Single static method: ScalarConverter::convert(const std::string& literal).
  • Must handle pseudo-literals: nan, nanf, +inf, -inf, +inff, -inff.
  • Print "impossible" if overflow/invalid, and "Non displayable" for non-printable chars.

    ScalarConverter(); // Non-instantiable

Exercise 01: Serialization

Pointer-to-Integer Reinterpretation and Back.

ex01/ | Serializer.{hpp,cpp}, Data.hpp

Key Concepts & Implementation

Use uintptr_t (an unsigned integer type capable of holding a pointer) along with reinterpret_cast to turn a memory address into an integer and restore it without bit alteration.

struct Data {
    std::string name;
    int value;
};

class Serializer {
private:
    Serializer();
public:
    static uintptr_t serialize(Data* ptr) {
        return reinterpret_cast<uintptr_t>(ptr);
    }
    static Data* deserialize(uintptr_t raw) {
        return reinterpret_cast<Data*>(raw);
    }
};

Exercise 02: Identify Real Type

Polymorphic Real-Type Identification without std::typeinfo.

ex02/ | Base.{hpp,cpp}, A.hpp, B.hpp, C.hpp, main.cpp

Key Concepts & Dynamic Casting Technique

Since std::typeinfo (typeid) is forbidden, we use dynamic_cast to discover the underlying actual type (A, B, or C) of a polymorphic Base reference or pointer.

1. Pointer Identification (Base* p)

When dynamic_cast fails on a pointer, it safely returns nullptr.

void identify(Base* p) {
    if (dynamic_cast<A*>(p)) std::cout << "A\n";
    else if (dynamic_cast<B*>(p)) std::cout << "B\n";
    else if (dynamic_cast<C*>(p)) std::cout << "C\n";
}

2. Reference Identification (Base& p)

References cannot be null! Failed dynamic_cast on reference throws std::bad_cast.

void identify(Base& p) {
    try {
        (void)dynamic_cast<A&>(p);
        std::cout << "A\n"; return;
    } catch (...) {}
    // Repeat try-catch for B& and C&
}
