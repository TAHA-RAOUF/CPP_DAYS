3. Ford-Johnson Algorithm (Merge-Insertion Sort)

The Ford-Johnson algorithm minimizes the total number of comparisons required to sort $N$ elements by combining pairwise sorting, recursive sorting of larger elements, and binary insertion ordered by the Jacobsthal Sequence.

Step 1: Pairwise Comparison

Group elements into pairs and sort each pair so that the larger element is first.

Input: [3, 5, 9, 7, 4] Pairs: (5, 3), (9, 7) | Stray element: 4
Step 2: Recursive Sort of Main Chain

Extract the larger elements from each pair to create the Main Chain and recursively sort them.

Main Chain: [5, 9] -> Recursive Sort -> [5, 9] Sorted Pairs: (5, 3), (9, 7) Pend: [3, 7]
Step 3: Jacobsthal Sequence Insertion

The first pend element (b1 = 3) is placed at the front of the main chain. Subsequent elements from pend are inserted into main chain using binary search in Jacobsthal order (1, 3, 5, 11, 21, ...).

Initial result with b1: [3, 5, 9] Insert remaining pend (7) via Binary Search into [3, 5, 9] -> Inserted between 5 and 9 Result so far: [3, 5, 7, 9]
Step 4: Stray Element Insertion

If $N$ was odd, insert the un-paired stray element (4) using binary search.

Insert stray (4) into [3, 5, 7, 9] -> [3, 4, 5, 7, 9] Final Sorted Result: [3, 4, 5, 7, 9]

4. Why Use Jacobsthal Numbers?

Jacobsthal numbers defined by $J_0 = 0, J_1 = 1, J_n = J_{n-1} + 2 J_{n-2}$ give the ideal group sizes for binary insertion. Inserting elements backward from the current Jacobsthal index guarantees that binary search bounds remain optimal ($2^k - 1$), minimizing comparisons!
